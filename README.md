# Telegram Bot - Welhome

Телеграм-бот на Python с использованием aiogram v3 для помощи в вопросах недвижимости.

## Требования

- Python 3.10+
- aiogram 3.x
- python-dotenv
- openai>=1.0

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Откройте `.env` и укажите ваш токен бота и настройки LLM провайдера:
```
BOT_TOKEN=your_bot_token_here
ADMIN_CHAT_ID=0
LOGO_PATH=assets/logo.png

# LLM Provider selection (proxyapi or openrouter)
LLM_PROVIDER=proxyapi

# ProxyAPI configuration (основной провайдер)
PROXYAPI_API_KEY=put_key_here
PROXYAPI_BASE_URL=https://openai.api.proxyapi.ru/v1
PROXYAPI_MODEL=openai/gpt-5.1
PROXYAPI_MAX_TOKENS=1500

# OpenRouter configuration (опционально, для отката)
OPENROUTER_API_KEY=
OPENROUTER_MODEL=openai/gpt-5.1
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
OPENROUTER_SITE_URL=http://localhost
OPENROUTER_APP_NAME=Welhome Bot
OPENROUTER_MAX_TOKENS=1500
```

### Настройка ProxyAPI

Для работы LLM-ответов необходимо получить API ключ ProxyAPI:

1. Зарегистрируйтесь на [console.proxyapi.ru](https://console.proxyapi.ru/)
2. Создайте API ключ в настройках аккаунта
3. Добавьте ключ в `.env` файл как `PROXYAPI_API_KEY`

**Важно:**
- Без `PROXYAPI_API_KEY` (или `OPENROUTER_API_KEY` при `LLM_PROVIDER=openrouter`) бот будет работать, но LLM-ответы будут отключены (будет возвращаться сообщение "Сервис временно недоступен, попробуйте позже.")
- Модель по умолчанию: `openai/gpt-5.1` (можно изменить через `PROXYAPI_MODEL`)
- Формат модели может быть с префиксом провайдера (`openai/gpt-5.1`) или без (`gpt-5.1`)
- Base URL: `https://openai.api.proxyapi.ru/v1` (OpenAI-compatible API)

### Настройка OpenRouter (альтернатива/откат)

Если нужно использовать OpenRouter вместо ProxyAPI:

1. Установите `LLM_PROVIDER=openrouter` в `.env`
2. Зарегистрируйтесь на [OpenRouter.ai](https://openrouter.ai/)
3. Создайте API ключ в настройках аккаунта
4. Добавьте ключ в `.env` файл как `OPENROUTER_API_KEY`

## Запуск

Запустите бота командой:
```bash
python -m bot.main
```

## Функциональность (v1.1)

### Основные функции

- `/start` - запуск бота, онбординг, показ меню
- `/menu` - повторный показ меню
- Обработка свободного ввода текста с генерацией ответов через LLM (ProxyAPI/OpenRouter)
- Контекст диалога в рамках сессии (использование уже собранных данных)
- Автоматическое добавление дисклеймеров к ответам
- Логирование входящих сообщений

### Меню (5 пунктов)

1. **🏠 Аренда** - с inline-подпунктами "Снять" / "Сдать"
2. **🏡 Покупка и продажа** - с inline-подпунктами "Купить" / "Продать"
3. **📊 Аналитика и рынок** - вопросы по рынку недвижимости
4. **📄 Документы и налоги** - вопросы по документам и налогам (строгий дисклеймер)
5. **ℹ️ О компании / 👨‍💼 Связь со специалистом** - информация о компании и запуск консультации

### Дисклеймеры

- **Дисклеймер A (мягкий)** - по умолчанию для всех ответов
- **Дисклеймер D (строгий)** - автоматически для тем налогов и документов

Дисклеймеры добавляются автоматически на уровне кода (safety-net), даже если LLM сам добавил дисклеймер.

### Обратная связь (👍/👎)

- **👍 Полезно** - простая благодарность
- **👎 Некорректно** - выбор причины:
  - ❌ ошибка фактов
  - 🤷 непонятно
  - ⚠️ опасный / сомнительный совет
  - 📝 другое (с запросом комментария)

При негативной оценке админу отправляется:
- Причина
- Последний вопрос и ответ
- История диалога (5-10 последних сообщений)
- Информация о пользователе

### Консультация специалиста

Пошаговый сбор данных с проверкой session data (пропуск уже заполненных полей):

1. Город/район
2. Тип объекта
3. Тип запроса (купить/продать/снять/сдать/другое)
4. Бюджет (или "не знаю")
5. Срочность
6. Детали

При отправке админу включается:
- Дата и время
- Username и user_id
- Исходный текст запроса (если есть)
- Все собранные ответы

- Команда `/cancel` и кнопка "❌ Отмена" для выхода из сценария

### Принцип работы ответов (v1.1)

**Главный принцип:** Сначала полезный ответ → затем дисклеймер → после этого (опционально) предложение специалиста.

Бот никогда не уходит от ответа из-за "риска" - всегда даёт ориентиры, рамки, факторы, даже при неопределённости. Только после этого может предложить консультацию специалиста как дополнительную опцию.

**Примечание:** Для получения заявок на консультацию и фидбека необходимо установить `ADMIN_CHAT_ID` в `.env` файле (ID чата, куда будут приходить заявки). Если `ADMIN_CHAT_ID=0` или не задан, заявки будут логироваться, но не отправляться.
